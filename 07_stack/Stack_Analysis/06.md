# Analysis of Stack Operations

## This demonstrates 32-bit register push and pop stack mechanics in 32-bit NASM assembly system.

Program Flow
At the start ESP points to the top of the stack.

1. Initialization of EAX (0x11223344) and EBX (0x1234).
2. Push EAX decrements ESP by 4 bytes (because it is 32-bit code) and writes EAX to the stack.
3. Push EBX decrements ESP by 4 bytes and writes EBX to the stack.
**ESP is now 8 bytes lower than what it was at the start.**
4. Pop EBX reads the top stack value (0x1234) into EBX. ESP increments by 4 bytes.
5. Pop EAX reads the top stack value (0x11223344) into EAX. ESP increments by 4 bytes.
The program exits using Linux 32-bit interrupt int 0x80.

In 32-bit execution, stack pushes and pops alter ESP by 4 bytes per register operation. Values are retrieved in Last-In, First-Out (LIFO) order.
