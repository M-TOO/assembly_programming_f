# Analysis of Stack Operations

## This demonstrates the basic operations of a stack in 64-bit NASM assembly system, pushing two registers onto the stack and popping them to different registers.

## Program Flow

At the start RSP points to the top of the stack.

1. Initialization of the values into the registers RAX (100) and RBX (200).
2. Push RAX decrements the RSP by 8 bytes (because it is 64-bit code). This makes the value 100 written to the top of the stack.
3. Push RBX decrements the RSP once more by 8 bytes. The value 200 is written to the stack.
**RSP is now 16 bytes lower than what it was at the start.**
4. Pop RCX. This reads the value at the current RSP (200) into RCX. RSP increments by 8 bytes.
5. Pop RDX. This reads the value at the top (100) into RDX. RSP is incremented by 8 bytes.
The program exits.

The stack operates as a LIFO (Last-In, First-Out) structure. Values pushed in the order (RAX, RBX) were popped into (RCX, RDX). The RSP accurately tracked the top of the stack, decreasing on push and increasing on pop.
