# Analysis of Stack Operations

## This demonstrates pushing and restoring register values using the stack in 64-bit NASM assembly system.

Program Flow
At the start RSP points to the top of the stack.

1. Initialization of RAX (0x1122334455667788) and RBX (0x1234).
2. Push RAX decrements RSP by 8 bytes and stores RAX value on top of stack.
3. Push RBX decrements RSP by 8 bytes and stores RBX value on top of stack.
**RSP is now 16 bytes lower than what it was at the start.**
4. Pop RBX reads the value on top of stack (0x1234) into RBX. RSP increments by 8 bytes.
5. Pop RAX reads the next value (0x1122334455667788) into RAX. RSP increments by 8 bytes.
The program exits.

The stack serves as a temporary storage area to preserve register contents. Popping items in the reverse order of pushing restores registers back to their original values.
