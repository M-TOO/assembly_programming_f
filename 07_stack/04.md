# Analysis of Stack Operations

## This demonstrates 32-bit stack frame creation and local variable allocation in 32-bit NASM assembly system.

## Program Flow
At the start ESP points to the top of the stack.

1. Call work pushes the 4-byte return address onto the stack. ESP decrements by 4 bytes (because it is 32-bit code).
2. Push EBP saves the caller's base pointer onto the stack. ESP decrements by 4 bytes.
3. MOV EBP, ESP establishes the new stack frame base.
4. SUB ESP, 8 decrements ESP by 8 bytes to make space for two 4-byte local variables.
   - Value 100 is written to [EBP - 4].
   - Value 200 is written to [EBP - 8].
   - Values are loaded into EAX and EBX.
**ESP is now 16 bytes lower than what it was at the start.**
5. MOV ESP, EBP restores ESP to clean up the allocated local space.
6. Pop EBP restores the caller's base pointer. ESP increments by 4 bytes.
7. RET pops the return address into EIP (ESP increments by 4 bytes) and control returns.
The program exits using Linux 32-bit interrupt int 0x80.

In 32-bit architecture, stack adjustments occur in 4-byte increments. Local variables are placed relative to EBP, and ESP is restored before returning to prevent stack misalignment.
