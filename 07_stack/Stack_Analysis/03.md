# Analysis of Stack Operations

## This demonstrates function execution flow and return address handling using the stack in 64-bit NASM assembly system.

## Program Flow
At the start RSP points to the top of the stack.

1. Initialization of value 10 into RAX.
2. Call calculate automatically pushes the 8-byte address of after_call onto the stack. RSP decrements by 8 bytes.
3. Execution jumps to calculate, where value 5 is added to RAX (RAX becomes 15).
4. RET pops the return address off the top of the stack into RIP. RSP increments by 8 bytes.
5. Control continues at after_call.
The program exits.

The stack automatically stores instruction addresses during call instructions. When ret is executed, the CPU pops that address to return control to the instruction right after the function call.
